# Business Rules

## Period comparison
- Compare B25 with B26.
- Align YTD using the same elapsed day within each admissions period.

## Projection
- Use elapsed days and actual admissions run rate.
- Track actual YTD, elapsed days, remaining days, current rate, required rate, projected close, and gap.

## Targets
- B26 institutional target: 2,400 admissions.
- Allocate career targets proportionally so they reconcile to 2,400.
- Preserve campus targets from the source Excel.
- When a campus has no target in the source, use 0.

## Quality gate
Do not finalize measures or visuals until source totals, dates, periods, careers, campuses, and targets reconcile with the validated source.
